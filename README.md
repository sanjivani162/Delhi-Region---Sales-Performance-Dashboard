## Delhi Region - Sales Performance Dashboard

An interactive sales analytics dashboard built in Excel/Power BI to track regional performance.

**Key Features:**
- Dynamic Region Slicer (30+ regions) with Delhi focus
- Sales Executive wise - Total Sales, Target Hit %, Away From Target %
- Visuals: Bar Chart, Column Chart, Pie Distribution & Trend Analysis
- KPIs: Grand Total Sales = 548, Avg Target Hit = 98%+

**Tools Used:** Advanced Excel, Power BI, Slicers, DAX

**Insight:** Delhi leads with 548 sales, while Santa Pome is top performer with 439 sales.
